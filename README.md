# 商品検索アプリ（Product Search App）

Next.jsとTypeScriptを使用して作成した商品検索アプリです。

商品データをJSONファイルから取得し、商品名やカテゴリーによる検索・絞り込みができます。

また、検索条件をURLのクエリパラメータと連動させることで、検索結果の共有やページ再読み込み後の条件復元にも対応しています。

## 主な機能

- **商品一覧表示**
  - JSONファイルから商品データ30件を取得して表示
- **商品名検索**
  - 入力したキーワードを含む商品を検索
- **カテゴリー絞り込み**
  - PC・スマホ・タブレット・周辺機器から選択
- **複数条件での検索**
  - 商品名とカテゴリーを組み合わせた検索
- **検索結果の0件表示**
  - 該当する商品がない場合にメッセージを表示
- **URLクエリパラメータとの連動**
  - 検索条件をURLに反映
  - URLから検索条件を読み込み
  - 検索条件を含むURLを共有可能
  - ページ再読み込み後も検索条件を復元

## 学んだこと

### 1. useStateによる状態管理

`useState`を使用して、商品データ・検索キーワード・カテゴリーなどの状態を管理しました。

入力内容が変更されたときに状態を更新し、その状態に応じて画面が再レンダリングされる仕組みを学びました。

### 2. useEffectによる処理の実行

`useEffect`を使用して、コンポーネントの初回表示時に商品データを取得する処理や、URLから検索条件を読み込む処理を実装しました。

また、検索条件が変更されたときにURLを更新する処理も実装しました。

### 3. fetchによるデータ取得

`fetch`を使用して、`public/products.json`に保存した商品データを取得しました。

取得したJSONデータをJavaScriptで扱える形式に変換し、Reactの状態として管理する流れを学びました。

### 4. filterによる検索・絞り込み

配列の`filter`メソッドを使用して、商品名とカテゴリーの条件に一致する商品だけを抽出しました。

複数の検索条件を組み合わせる方法や、検索結果が0件になるケースへの対応を学びました。

### 5. URLSearchParamsによるURLの操作

`URLSearchParams`を使用して、URLのクエリパラメータを取得・設定する方法を学びました。

検索条件をURLに反映することで、検索状態を共有・復元できる仕組みを実装しました。

### 6. useEffectとURL同期の制御

ページの初回表示時には、まずURLから検索条件を読み込む必要があります。

そのため、`isInitialized`という状態を用意し、初期化が完了する前にURLが上書きされないように制御しました。

複数の処理が実行される順番や、状態の変化によって処理が実行される仕組みについて理解を深めました。

## 工夫した点・理解できたこと

- 商品データと検索条件を別々の状態として管理したこと
- 商品データを取得する処理と、検索条件をURLに反映する処理を分けたこと
- 商品名とカテゴリーの両方に一致する場合のみ表示するようにしたこと
- URLを共有するだけで、同じ検索条件を再現できるようにしたこと
- 初期化前のURL上書きを防ぐため、処理の実行タイミングを制御したこと

## MODERN SELECT：デザイン・機能拡張

### 1. 概要

既存の商品検索アプリをベースに、高級感のあるECサイト「MODERN SELECT」を制作しました。

アイボリーとブラウンを基調としたデザインに変更し、商品画像の追加、価格順の並び替え、お気に入り登録などの機能を実装しました。

PCとスマートフォンの両方で使いやすい、レスポンシブデザインに対応しています。

### 2. 実装した機能

**商品検索・絞り込み**
- 商品30件の一覧表示
- 商品名による検索
- カテゴリーによる絞り込み
- 複数条件を組み合わせた検索
- 検索結果件数の表示
- 検索条件のリセット
- URLクエリパラメータによる検索条件の保存・復元

**追加機能**
- 価格の安い順・高い順への並び替え
- ハートボタンによるお気に入り登録・解除
- お気に入り登録件数の表示

※お気に入り情報はReactのstateで管理しているため、ページを再読み込みすると初期化されます。

**デザイン**
- アイボリー・ブラウンを基調とした配色
- ブランドロゴ・ナビゲーションの設置
- 商品画像30枚の追加
- 商品カードのホバーアニメーション
- PC4列・スマートフォン2列の商品一覧
- ブランド説明・CONTACT・著作権表記を含むフッター
- スマートフォン表示でのナビゲーション折り返し対応

### 3. 制作手順

1. 既存の商品検索アプリから `modern-select` ブランチを作成
2. 商品画像30枚を準備し、`products.json` の画像パスを更新
3. `globals.css` でサイト全体の配色を変更
4. ヘッダー・ナビゲーションを作成
5. 商品一覧をレスポンシブなグリッドレイアウトに変更
6. 商品カードの画像・文字・余白・ホバー効果を調整
7. 検索フォームとカテゴリー選択欄をデザイン
8. `useState` と `sort()` で価格順の並び替えを実装
9. `length` で検索結果件数を表示
10. 検索条件のリセットボタンを実装
11. `useState` でお気に入りの商品IDを管理
12. `includes()`・`filter()`・スプレッド構文でお気に入りの登録・解除を実装
13. 三項演算子でハートの表示を切り替え
14. `favorites.length` でお気に入り件数を表示
15. フッターを作成
16. Chromeの開発者ツールでスマートフォン表示を確認
17. `flex-wrap` を使ってナビゲーションのはみ出しを修正

### 5. 学習したこと

**Reactの状態管理**

`useState` を使って、検索キーワード・カテゴリー・並び替え条件・お気に入り情報を管理しました。

状態が更新されるとReactが画面を再レンダリングし、商品一覧やハートの表示が更新される仕組みを学びました。

**配列操作**

- `filter()`：条件に合う商品を抽出する
- `sort()`：価格順に商品を並び替える
- `map()`：商品データから商品カードを生成する
- `includes()`：お気に入り登録済みか確認する
- `length`：配列内のデータ件数を取得する
- スプレッド構文：既存の配列を展開して新しい要素を追加する

**レスポンシブデザイン**

Tailwind CSSの `grid-cols-2`・`lg:grid-cols-4` を使い、画面幅に応じて商品一覧の列数を変更しました。

また、スマートフォン表示でナビゲーションが画面外にはみ出す問題を確認し、`flex-wrap` と余白の調整によって修正しました。

### 6. 工夫した点・苦労した点

**既存機能を維持したままデザインを変更**

検索・カテゴリー絞り込み・URLによる検索条件の復元など、既存の機能を維持しながら、画面デザインを変更しました。

**お気に入り機能の実装**

商品IDを配列で管理し、登録済みかどうかに応じて追加・削除の処理を切り替えました。

**スマートフォン表示の修正**

PCでは正常に表示されていたナビゲーションが、スマートフォンでは画面幅を超えてしまう問題が発生しました。

Chromeの開発者ツールで問題を確認し、Tailwind CSSのレスポンシブ対応によって改善しました。
